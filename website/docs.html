TinyTalk Language Guide

TinyTalk (.tnt) combines the live-programming heritage of Smalltalk with Pythonic elegance, zero-cost C performance, sub-millisecond JIT compilation, and direct hardware lowering from bare-metal silicon to quantum statevectors.

📦 Installation & Setup

TinyTalk can be installed directly from PyPI via pip, compiled from source, or used via standalone binary releases:

TERMINAL • INSTALL VIA PYPI 
pip install --upgrade tinytalk-lang

Verify that the compiler and CLI are properly registered on your PATH:

TERMINAL • VERIFY COMPILER 
$ tnt --version
TinyTalk v8.0.0 (x86_64-pc-windows-msvc, 0ms GC, Auto-TCO, WebGPU, Quantum)

⚡ Hello TinyTalk

TinyTalk programs use clean, readable syntax. Save the following code as fib.tnt:

TINYTALK • fib.tnt 
def fib(n: i64) -> i64:
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

def main():
    let ans: i64 = fib(30)
    print("Fibonacci(30) =", ans)
    return 0

Execute immediately via JIT or compile to a native standalone executable:

TERMINAL • RUN & BUILD 
# 1. Instant JIT execution
$ tnt run fib.tnt
Fibonacci(30) = 832040

# 2. Standalone Windows PE32+ executable (no Python or runtime required)
$ tnt build fib.tnt --target exe -o fib.exe
[TinyTalk] Built standalone Windows x86-64 PE32+ executable -> fib.exe (11776 bytes)

$ .\fib.exe
Fibonacci(30) = 832040

🛠️ CLI Command Reference

The tnt toolchain provides unified commands for development, profiling, and production deployment:

Command Description
tnt run <file.tnt> Compiles and executes a .tnt file immediately via the native x86-64 JIT engine.
tnt build <file.tnt> --target [exe|wasm|elf|macho|c] Lowers directly into standalone executables, WebAssembly, or ANSI C11 source.
tnt repl Starts the Smalltalk-inspired interactive live shell with real-time expression evaluation.
tnt bench Executes the head-to-head performance benchmark suite against CPython 3.14.
tnt inspect <file.tnt> Inspects inferred static types, Middle Intermediate Representation (MIR), and native assembly.
tnt studio Launches the 2D Morphic visual canvas studio and Socratic Inquisitor Agent.
tnt web serve <dir> --port <p> Serves static applications or reactive full-stack web sites with zero overhead.
tnt gatekeeper Runs the 5-Stage Zero-Defect certification pipeline before publishing releases.

⚙️ Universal Differentiable Physics

TinyTalk features first-class reverse-mode automatic differentiation (DiffVar) and symplectic Hamiltonian integrators preserving phase-space volume and Noether conservation laws:

TINYTALK • autodiff.tnt 
from diff_physics import DiffVar

def main():
    let x = DiffVar(2.0)
    let y = DiffVar(3.0)
    let z = (x * x) + (x * y)
    z.backward()
    
    print("dz/dx =", x.grad)  # (2 * 2.0) + 3.0 = 7.0
    print("dz/dy =", y.grad)  # 2.0
    return 0

⚛️ Quantum Circuits & OpenQASM 3.0

Native statevector simulation, Bell EPR pair entanglement, and direct lowering to OpenQASM 3.0 for physical quantum processors:

TINYTALK • quantum_bell.tnt 
from quantum import QuantumCircuit
from qasm import to_openqasm3

def main():
    let qc = QuantumCircuit(2)
    qc.h(0)     # Hadamard gate on qubit 0: creates (|0> + |1>)/sqrt(2)
    qc.cx(0, 1) # CNOT gate entangles qubit 0 and 1: (|00> + |11>)/sqrt(2)
    
    let qasm = to_openqasm3(qc)
    print("Generated OpenQASM 3.0 Program:")
    print(qasm)
    return 0

from loihi2 import emit_loihi_microcode
