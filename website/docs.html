TinyTalk Language Guide

TinyTalk (.tnt) and Black Mamba (.bmb) combine Smalltalk live-programming heritage with Pythonic readability, zero-cost C performance, sub-millisecond compilation, and universal hardware backends from silicon to quantum statevectors.

📦 Installation & Setup

TinyTalk can be installed via PyPI, direct standalone binary download, or cloned directly from GitHub.

pip install --upgrade tinytalk-lang

🚀 Quickstart: Hello TinyTalk

Create a file named hello.tnt:

TINYTALK • hello.tnt 
def fib(n: i64) -> i64:
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

def main():
    let result: i64 = fib(30)
    print("Fibonacci(30) =", result)
    return 0

Run it with instantaneous JIT execution or compile it directly to a 5.5 KB native standalone executable:

TERMINAL • RUN & BUILD 
# Direct Instant JIT:
$ tnt run hello.tnt
Fibonacci(30) = 832040

# Native 5.5 KB Standalone Executable (.exe / .elf / .macho):
$ tnt build hello.tnt --target pe -o hello.exe
[TinyTalk Compiler] Built standalone PE32+ executable (5,584 bytes) in 0.04s.

⚙️ Universal Differentiable Physics (Phase 16)

TinyTalk features first-class reverse-mode automatic differentiation graph tape (`DiffVar`) and symplectic Hamiltonian Velocity-Verlet integrators that strictly preserve phase-space volume and Noether's conservation laws.

TINYTALK • physics_tape.tnt 
from tnt.diff_physics import DiffVar
from tnt.hamiltonian import HamiltonianSystem, Particle
from tnt.physics_verify import verify_noether

def main():
    # Reverse-Mode Automatic Differentiation Graph
    let x = DiffVar(2.0)
    let y = DiffVar(3.0)
    let z = (x * x) + (x * y)
    z.backward()
    
    print("dz/dx =", x.grad)  # (2 * 2.0) + 3.0 = 7.0
    print("dz/dy =", y.grad)  # 2.0
    return 0

⚛️ Fault-Tolerant Quantum & OpenQASM 3.0 (Phase 15)

TinyTalk natively manages complex statevectors, Bell EPR entanglement pairs, and quantum circuit lowering to OpenQASM 3.0 compatible with physical superconducting and trapped-ion quantum QPUs.

TINYTALK • epr_bell.tnt 
from tnt.quantum import QuantumCircuit
from tnt.qasm import to_openqasm3

def main():
    let qc = QuantumCircuit(2)
    qc.h(0)           # Hadamard gate creates superposition (|0> + |1>)/sqrt(2)
    qc.cx(0, 1)       # CNOT gate entangles qubit 0 and 1 -> (|00> + |11>)/sqrt(2)
    
    let qasm = to_openqasm3(qc)
    print("Generated OpenQASM 3.0 Program:")
    print(qasm)
    return 0

🧠 Neuromorphic Silicon & Intel Loihi 2 (Phase 13)

Simulate biological Leaky Integrate-and-Fire (LIF) spiking neural networks, Spike-Timing-Dependent Plasticity (STDP) learning, and compile directly to microcode for neuromorphic silicon processors.

TINYTALK • snn_loihi.tnt 
from tnt.neuromorphic import LIFNeuron
from tnt.loihi2 import emit_loihi_microcode

def main():
    let neuron = LIFNeuron(v_thresh=1.0, tau_m=20.0, v_rest=0.0)
    for step in range(10):
        let spiked = neuron.step(current=0.3)
        print("Step:", step, "Membrane Potential:", neuron.v, "Spiked:", spiked)
    return 0

🛠️ CLI Command Reference

The tnt executable exposes zero-friction commands for development, testing, and production deployment:

Command Description
tnt run <file.tnt> Executes TinyTalk source code instantly via the native JIT engine.
tnt build <file.tnt> --target [pe|elf|macho|wasm|all] Compiles to standalone executables or WebAssembly with 0 dependencies.
tnt gatekeeper Executes the 5-Stage Zero-Defect certification test suite.
tnt web dev <app.tnt> Starts zero-cold-start web development server with live reload.
tnt lsp --stdio Spawns the Language Server Protocol daemon for editor integration.
