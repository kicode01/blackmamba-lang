Universal Multi-Target Architecture

Compile Everywhere. Zero Friction.

One clean `.tnt` source file lowers directly into every high-performance backend format without external toolchains.

🪟
Windows PE32+ Executable .exe

Zero-dependency native Windows binary with built-in structured exception handling and pure x86-64 machine code.

🐧
Linux ELF64 Binary .elf

Raw Linux binary emitting direct syscalls with zero glibc or musl linkage overhead.

🍎
macOS Mach-O Binary .macho

Native ARM64 Apple Silicon and x86-64 executable targeting macOS Darwin with signed headers.

🌐
WebAssembly & WAT .wasm / .wat

Pure client-side browser execution with zero memory virtualization overhead and instant WebGPU interop.

⚡
C11 Source & LLVM IR .c / .ll

Human-readable, audit-ready ANSI C11 emission or LLVM bitcode for enterprise verification pipelines.

🎮
WebGPU & Vulkan Shaders .wgsl / .spv

Direct compilation to WebGPU WGSL compute shaders and Vulkan SPIR-V binaries for hardware-accelerated tensor math.
