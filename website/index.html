Architecture

        
How Black Mamba Eliminates Bottlenecks

        

          Synthesizes the best ideas of systems languages while preserving standard Python syntax.
        

      


      

        

          

            
Register Unboxing

            
0-Byte Values in CPU Registers

            

              Standard Python boxes every primitive integer into a 28-byte PyLongObject heap allocation. 
              Black Mamba keeps primitive integers and unboxed value structs directly in 64-bit hardware registers (RAX, RBX) with zero memory dereferences.
            

          

          

            Integer Heap Overhead
            CPython: 28B
            BMB: 0B
          

        


        

          

            
Memory Architecture

            
Lexical Arena Lifetimes

            

              No borrow-checker cognitive burden (&mut / borrowed annotations) and no stop-the-world garbage collection pauses. 
              Ephemeral allocations are automatically bounded by function stack frames using escape-analyzed arena watermarks that rewind in 1 CPU cycle.
            

          

          

            Stop-the-World GC Pause
            0.000 ms
          

        


        

          

            
Tail Recursion

            
Automatic TCO (Auto-TCO)

            

              CPython incurs a massive 2,112-byte call frame per invocation, quickly terminating on deep recursion with RecursionError. 
              Black Mamba's SSA MIR optimizer automatically lowers tail calls into zero-overhead register jumps, executing millions of iterations in constant stack space.
            

          

          

            Stack Growth @ 5,000,000 calls
            0 Bytes
          

        


        

          

            
Concurrency

            
Zero-GIL Multi-Threading

            

              True native hardware concurrency. Includes Vyukov lock-free bounded MPMC channels (chan.bmb), 
              hardware atomic CAS (lock cmpxchg), and parallel data loops (par_for) scaling linearly across all physical CPU cores.
            

          

          

            Global Interpreter Lock
            None (Eliminated)
          

        


        

          

            
Deployment

            
~20 KB Zero-Base Containers

            

              Generate pure-Python OCI/Docker image tarballs (FROM scratch) containing a static Linux ELF64 binary with zero external C compiler, zero Docker daemon, and zero Linux virtual machines required at build time.
            

          

          

            Docker Image Size
            ~20.0 KB
          

        


        

          

            
Edge AI

            
Native GGUF Inference Engine

            

              Load GGUF format weights and execute quantized matrix-vector arithmetic (Q4_0 / Q8_0 GEMV) for streaming local LLM generation without PyTorch or external CUDA driver toolkits.
            

          

          

            External AI Dependencies
            Zero (Pure Native)
