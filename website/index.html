Same clean Python code. Radically different execution models on bare metal.

Architecture

How Black Mamba Eliminates Bottlenecks

Synthesizes the best ideas of systems languages while preserving standard Python syntax.

Register Unboxing

0-Byte Values in CPU Registers

Standard Python boxes every primitive integer into a 28-byte PyLongObject heap allocation. Black Mamba keeps primitive integers and unboxed value structs directly in 64-bit hardware registers (RAX, RBX) with zero memory dereferences.

Integer Heap Overhead CPython: 28B BMB: 0B
Memory Architecture

Lexical Arena Lifetimes

No borrow-checker cognitive burden (&mut / borrowed annotations) and no stop-the-world garbage collection pauses. Ephemeral allocations are automatically bounded by function stack frames using escape-analyzed arena watermarks that rewind in 1 CPU cycle.

Stop-the-World GC Pause 0.000 ms
Tail Recursion

Automatic TCO (Auto-TCO)

CPython incurs a massive 2,112-byte call frame per invocation, quickly terminating on deep recursion with RecursionError. Black Mamba's SSA MIR optimizer automatically lowers tail calls into zero-overhead register jumps, executing millions of iterations in constant stack space.

Stack Growth @ 5,000,000 calls 0 Bytes
Concurrency

Zero-GIL Multi-Threading

True native hardware concurrency. Includes Vyukov lock-free bounded MPMC channels (chan.bmb), hardware atomic CAS (lock cmpxchg), and parallel data loops (par_for) scaling linearly across all physical CPU cores.

Global Interpreter Lock None (Eliminated)

Frequently Asked Questions

Direct technical answers to common architecture and design queries.

How does memory management work without GC or borrow checker?

Black Mamba utilizes escape-analyzed lexical memory arenas. Ephemeral variables and structs are allocated from thread-local arena watermarks that rewind in a single CPU cycle upon function exit. Long-lived handles utilize atomic reference counts. There is zero stop-the-world GC latency and zero lifetime annotation ceremony.

Does Black Mamba require MSVC, GCC, or Clang?

No. The compiler includes fully self-contained machine code encoders for x86-64 and WebAssembly, along with custom pure Python linkers for Windows PE32+, Linux ELF64, and OCI container tarballs. You can build binaries for Linux from a Windows laptop without Docker or toolchains.

Can I speed up my existing CPython codebase with Black Mamba?

Yes. With --target ext, Black Mamba compiles hot computational functions into a native Windows .pyd or Linux .so C-extension using METH_FASTCALL dispatch. You can simply import my_module in Python and achieve up to 30.5x speedups.

How is Black Mamba different from Mojo or PyPy?

PyPy is a tracing JIT interpreter executing existing bytecode with a garbage collector. Mojo introduces new syntax keywords (fn, let, borrow annotations). Black Mamba maintains 100% Python syntax parity while compiling down to micro-footprint (5.5 KB) static standalone binaries.
